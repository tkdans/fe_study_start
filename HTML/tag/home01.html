<과제1>IP 주소란 무엇인가?

IP 주소의 정의

  • IP 주소 (Internet Protocol Address)는 인터넷에 연결된 각 장치를 식별하기 위한 고유한 숫자입니다.

  • 마치 집마다 고유한 주소가 있듯, 컴퓨터나 스마트폰도 네트워크 상에서 서로 통신하려면 주소가 필요합니다.

IP 주소의 종류

  • IPv4 32비트 주소 체계.약 43억 개 주소 제공.예: 192.168.0.1
  • IPv6 128비트 주소 체계. 예: 2001:0db8:85a3:0000:0000:8a2e:0370:73 사실상 무한대 주소 제공

공인 IP vs 사설 IP

공인 IP: 인터넷에서 직접 접근 가능한 주소. 웹사이트 서버 등에서 사용.

사설 IP: 내부 네트워크에서만 사용. 가정용 공유기나 회사 내부망에서 사용.

IP 주소의 역할

  • 데이터가 정확한 목적지로 전달되도록 안내하는 네트워크 내비게이션 시스템 역할을 합니다. 웹사이트 접속 시, 도메인 이름을 IP 주소로 변환해 해당 서버에 연결합니다.

도메인이란?

  • 도메인(Domain)은 인터넷에서 특정 웹사이트나 서비스를 찾기 위한 사람이 읽기 쉬운 주소입니다.
  • 본래 컴퓨터는 숫자로 된 IP 주소를 사용해 통신하지만, 사람들은 숫자를 외우기 어렵기 때문에 도메인이라는 이름 체계를 도입한 거예요.

도메인과 IP 주소의 관계

도메인은 IP 주소의 별명 같은 역할을 합니다.
예를 들어:
도메인: www.example.com
실제 IP 주소: 192.0.2.1

우리가 브라우저에 도메인을 입력하면,

**DNS(Domain Name System)**가 그 도메인을 해당 IP 주소로 변환해줍니다.

DNS란?
DNS는 인터넷의 전화번호부 같은 시스템입니다.
도메인을 입력하면 DNS가 해당하는 IP 주소를 찾아서 웹사이트에 접속할 수 있게 해줘요.

DNS 작동 흐름

    웹사이트에 접속할 때 DNS는 다음과 같은 과정을 거쳐 작동합니다.
  1. 도메인 입력
    2. 사용자가 브라우저에 www.google.com을 입력합니다.
  2. 캐시 확인
    3. 먼저 브라우저나 운영체제에 저장된 DNS 캐시를 확인해요. 이전에 접속한 적이 있다면 바로 IP 주소를 가져옵니다.
  3. 로컬 DNS 서버 질의
    4. 캐시에 없으면 인터넷 제공업체(ISP)의 DNS 서버에 IP 주소를 요청합니다.
  4. 계층적 DNS 탐색
    5. ISP DNS 서버도 모르면 다음 순서대로 상위 DNS 서버에 요청을 넘깁니다.
    - 루트 DNS 서버 → .com DNS 서버 → google.com DNS 서버
    - IP 주소 반환
    최종적으로 google.com에 해당하는 IP 주소를 찾아서 사용자에게 전달합니다.
    - 웹사이트 접속
    브라우저는 받은 IP 주소를 이용해 해당 서버에 연결하고 웹페이지를 표시합니다.

* DNS 캐시란?
- **DNS 캐시(Domain Name System Cache)**는 최근에 방문한 웹사이트의 도메인과 IP 주소 정보를 임시로 저장해두는 공간입니다.
- 목적은 간단해요: 같은 사이트에 다시 접속할 때 더 빠르게 연결되도록 하기 위해서예요.

*서버란 무엇인가?

**서버(Server)**
다른 컴퓨터나 장치에게 서비스를 제공하는 컴퓨터 또는 프로그램이에요.

서버의 주요 역할
- 데이터 저장: 웹사이트, 이미지, 영상 등 다양한 데이터를 저장
- 요청 처리: 클라이언트가 요청한 정보를 찾아서 응답
- 서비스 제공: 웹페이지, 이메일, 파일 공유 등 다양한 기능 제공
서버의 종류
| 웹 서버 | 웹사이트를 보여주는 서버 (예: Apache, Nginx) |
| 데이터베이스 서버 | 사용자 정보, 게시글 등을 저장하고 관리 (예: MySQL, Oracle) |
| 파일 서버 | 문서, 이미지, 영상 파일을 저장하고 공유 |
| 메일 서버 | 이메일 송수신을 처리 (예: Gmail의 서버) |
*로컬 서버 vs 인터넷 서버
- 로컬 서버: 내 컴퓨터에서만 작동하는 서버 (개발용, 테스트용)
- 인터넷 서버: 전 세계 어디서든 접속 가능한 서버 (실제 서비스용)

Live Server란?

Live Server는
VS Code에서 HTML, CSS, JavaScript 파일을 실시간으로 웹 브라우저에 띄워주는 개발용 서버입니다.
파일을 수정하고 저장하면, 브라우저가 자동으로 새로고침되어 변경 사항을 즉시 확인할 수 있어요
주요 기능
- 실시간 미리보기: 코드 저장 시 브라우저가 자동으로 새로고침됨
- 로컬 서버 실행: 내 컴퓨터를 웹 서버처럼 작동시켜 HTML 파일을 서비스함
- 모바일에서도 확인 가능: 설정을 통해 같은 네트워크의 다른 기기에서도 접속 가능

이 주소의 의미는 무엇인가?

http://127.0.0.1:5500/fe_study/html/start.html이란?
- 127.0.0.1은 루프백 주소 또는 localhost라고 불립니다.
- 내 컴퓨터 자신을 가리키는 IP 주소예요.
- Live Server가 이 주소를 사용하는 이유는 외부가 아닌 내 컴퓨터에서만 웹 페이지를 테스트하기 위해서입니다.

IP주소와 Live server의 차이

|정의 | 내 컴퓨터에서 실행되는 서버 | 네트워크 상의 장치 식별 주소 |
|예시 주소| http://127.0.0.1:5500 | 127.0.0.1192.168.0.5 |
| 접근 범위 | 기본적으로 내 컴퓨터에서만 접근 가능 | IP 설정에 따라 외부에서도 접근 가능 |

* 127.0.0.1이란?
- 127.0.0.1은 루프백 주소 또는 localhost라고 불립니다.
- 내 컴퓨터 자신을 가리키는 IP 주소예요.
- Live Server가 이 주소를 사용하는 이유는 외부가 아닌 내 컴퓨터에서만 웹 페이지를 테스트하기 위해서입니다.

*외부에서 로컬 서버에 접속하려면?
- 127.0.0.1 대신 **내 컴퓨터의 실제 IP 주소(예: 192.168.0.5)**를 사용해야 해요.
- Live Server 설정에서 host를 변경하면 같은 Wi-Fi에 있는 다른 기기에서도 접속 가능해집니다.
요약하자면, 로컬 서버는 개발용으로 내 컴퓨터에서 실행되는 서버이고, IP 주소는 그 서버에 접근하기 위한 주소입니다.
